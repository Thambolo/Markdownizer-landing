Webpage to Markdown.
The full feature guide.

Markdownizer converts the webpage you have open into clean Markdown for AI chats, notes, documentation, and coding workflows.

Choose what to extract, keep useful page structure, then copy the result or download a Markdown file. This page describes the available features and the limits to keep in mind.

Choose what
to bring along.

Capture content from the active webpage, with a visible selection preview and alternatives for different layouts.

Active-webpage conversion

Open Markdownizer from your browser toolbar and start the conversion. It works from an HTTP or HTTPS webpage you already have open, rather than asking an AI tool to fetch a bare URL.

Smart selection

The default capture mode looks for the page's article or main-content area, falling back to the page body when needed. This helps focus extraction on the main material rather than assuming that every element on the page is relevant.

Full-page capture

Enable Capture full page to capture the whole page body when Smart selection misses something important. A larger capture can also include more navigation and unrelated material, so review the result. This mode resets to Smart selection when you reopen the popup.

Selection preview on the webpage

See the area selected for capture before converting. The preview highlights visible text and outlines images and common controls. It can be turned off with Preview selection. This overlay shows capture scope; it is not a rendered Markdown preview.

Eligible embedded frames

The Include iframes option appears when eligible embedded content is detected. Markdownizer can include readable same-origin frames. Cross-origin or inaccessible frames are skipped; this is not universal support for embedded documents.

Handling for selected complex page types

There is targeted extraction handling for some CodeMirror editors, ReDoc API documentation, and simple CSS-generated text. Results depend on the page implementation and loaded content. These are compatibility measures, not a guarantee that every editor or dynamically generated page will convert.

Structure that
travels with the text.

Markdown expresses the relationships between headings, lists, references, and code without carrying the entire webpage layout.

Headings, lists, and text formatting

Convert heading hierarchy, ordered and unordered lists, and supported text formatting into Markdown. GitHub Flavored Markdown features include strikethrough. Review the hierarchy when the source page uses unusual markup.

Tables

Convert supported HTML tables to Markdown tables, keeping row and column relationships explicit. Nested tables are simplified, and missing headers may be inferred. Merged cells and complex visual groupings need particular attention during review.

Link labels and destinations

Markdown links carry the label and target together. Relative links are resolved against the page URL so the reference remains useful outside the original webpage. A link in the output does not mean an AI tool has opened or verified its destination.

Code blocks

Code is represented with fenced blocks, with language labels when detectable. Keep commands distinct from surrounding prose and inspect indentation, line breaks, and completeness before using the result in a coding workflow.

Image references

Supported images become Markdown image references. Relative image sources are resolved against the page URL. The normal Markdown output references images; downloading local image files is a separate option described below.

Standard interface controls

Some native controls can be represented as text or Markdown markers, including buttons, checkbox and radio states, selected options, and certain field values. Password and hidden input values are redacted by the extraction code, but other field values can appear in the result. Review captures for sensitive information; this is not a form-backup feature.

Copy it.
Save it. Reuse it.

Move converted content into your preferred AI chat, notes, editor, or documentation workflow.

Copy to clipboard

Copy the converted Markdown, then paste it wherever you want to use it. In an AI chat, add your own question alongside the source material. Markdownizer does not generate the AI response or send your prompt to an AI service for you.

Download a Markdown file

Save the result as a .md file with a filename derived from the page title. Keep it in a local notes collection, edit it, or reuse the source later. File-upload support depends on the destination app.

Optional image ZIP export

Enable Download images to build a ZIP containing the Markdown file, a README, and fetched images in an images/ directory. Image references in the bundled Markdown are rewritten to local paths. Eligible conversions start the bundle automatically when this option is enabled.

Image-download progress

Follow bundle progress in the popup. Once an image bundle has started building in the background, it can finish after the popup closes. This background ZIP operation is separate from the structural conversion service.

Image-download permissions and limits

Image downloads may request optional site-access permission. The bundle uses fetchable image references from the converted Markdown, not every visual asset on the page. Unavailable images, blob: references, timeouts, and size limits can leave some images out.

Current image-fetch limits are 15 MB per image, 60 MB in total, and a 10-second fetch timeout. The ZIP is not a complete offline archive of the website.

A workflow
you can adjust.

Use the popup settings to control capture scope and what happens after a successful conversion.

Preview selection

On by default. Turn the webpage highlight on or off; the preference is saved locally across popup sessions.

Capture full page

Off by default. Use it for the current capture when you want the whole page body instead of Smart selection. The mode is not retained when the popup is reopened.

Include iframes

Available when eligible embedded frames are detected. Eligible content is included automatically unless excluded. This choice is specific to the capture session rather than a permanently saved preference.

Download images

Off by default. This locally saved preference enables the optional image-bundle workflow and may require additional site-access permission.

Auto-download on success

Off by default. Enable it to download the Markdown file automatically after a successful conversion. The preference persists locally. When image bundling is active, its ZIP-download path takes precedence.

Status and output size

The popup reports conversion status and the resulting character count, then makes the output actions available. Conversion errors are surfaced rather than silently treated as successful output.

Use your normal paste shortcut

After copying, use Ctrl + V on Windows or Linux, or Cmd + V on Mac. These are the destination app's paste shortcuts, not a separate Markdownizer extraction hotkey.

Readable text
is restored locally.

A browser-and-backend conversion workflow, not an entirely offline or fully local converter.

Local text tokenization

Readable page text is replaced with tokens locally in your browser before structural conversion. The backend converts a structural skeleton, and the extension restores the original readable text in the Markdown in your browser.

Structural data still leaves the browser

The structural skeleton can include links, image references, and other HTML attributes. Do not assume that everything associated with a page stays on your device, or that page URLs are never transmitted.

Limited operational data

The privacy policy describes operational data used to operate, secure, and improve the service. It states that readable page text, final Markdown output, full page URLs, and raw HTML skeletons are not stored in analytics data.

You choose where to share the output

Copying the result into another app is a separate action. Review the Markdown and check sharing permissions before pasting private, personal, course, workplace, or client information into an AI service.

The privacy policy and terms of service are the authoritative policies. View the extension source on GitHub for implementation details.

Know the limits
before you convert.

Page structure, browser restrictions, and the destination tool all affect what you can do with the result.

Chrome and Chromium browsers

Markdownizer targets Chrome and Chromium-based browsers. Install from the Chrome Web Store in a browser that supports those extensions. Firefox and Safari support are not listed as available here.

Webpages, not every document format

The conversion flow targets ordinary HTTP and HTTPS webpages. Browser-internal pages are restricted. Markdownizer is not presented as a standalone PDF converter or an arbitrary local HTML-file converter.

Pages that require login

Markdownizer works from the page you can already open in your browser, but compatibility varies and not every logged-in page has been verified. It does not bypass access restrictions or give permission to share private content.

Large captures

Very large structural captures can exceed the conversion size limit. Smart selection may try a more focused extraction; full-page or iframe-inclusive captures may need to be reduced. The limit applies to the structural payload, not simply the number of words you see on screen.

Loaded content and complex layouts

Content that has not loaded, inaccessible frames, complicated tables, interactive widgets, and visual information may not be represented completely. Review the result, especially data tables and code, before relying on it.

AI and app behavior

Markdown does not remove an AI tool's context limits or guarantee a more accurate response. Markdownizer supplies converted source material; your chosen app handles the prompt, answer, or file. Check its limits and privacy settings separately.
