Prompt planning

How much source material should you include in an AI prompt?

There is no universal word count: include enough to support the task, but not unrelated context you have not reviewed.

Include the smallest complete amount of source material that lets the AI tool answer your specific question without losing the definitions, qualifications, or evidence the answer depends on. There is no fixed number of words that works for every model, account, task, or input type. Context limits vary by tool and may also depend on the conversation, system instructions, files, and other material already provided.

Start with the question, not with a whole webpage. If your task concerns one requirement or API parameter, a relevant section may be enough. If you ask for a study's limitations, omitting the methods or discussion may remove necessary context. The research-article guide shows what to keep together for that kind of question.

Define what the answer needs to rely on

Write down the expected output before collecting source text. Are you asking for a short explanation, a comparison, a checklist, or an outline? List the facts or requirements the answer must preserve. Then identify which source sections establish those facts and whether any other section qualifies them.

For a product comparison, you might need the specifications, pricing conditions, variant names, and date checked. For a coding question, you might need the relevant API instructions, prerequisites, and version. For research, you may need the study design alongside the result. A relevant caveat is often more useful than several paragraphs of unrelated background.

Trim carefully, not mechanically

  1. Keep source boundaries. Include a heading or short label so a section's scope remains clear.
  2. Keep definitions and units. Do not remove a glossary term, measurement unit, date range, or condition that changes what a value means.
  3. Keep qualifications near claims. Preserve limitations, exceptions, and footnotes with the statement they qualify.
  4. Remove repetition and unrelated navigation after checking that it is not a source note or required link.
  5. Preserve provenance. Add the title, URL, version or date, and source identity when those details affect interpretation.
  6. Check the destination tool. Its current input, file, image, and context limits determine what can be submitted.

If a source is longer than the tool accepts, split it into meaningful sections and ask focused questions. Keep a short running note of conclusions with links back to the source sections. Do not send fragments so small that a later answer cannot see the assumptions or caveats behind them.

Label instruction and source separately

Mark where your request ends and the source begins. Tell the AI whether it should use only the supplied text, how to handle missing information, and whether it should quote or summarize. For example:

Task: Compare the stated requirements in the source below.
Use only this source. Keep exceptions next to the rule they qualify.
If a detail is missing, list it instead of guessing.

Source: [title, version or date, URL]
[Paste the reviewed sections needed for this comparison]

This is an illustrative prompt, not a promise about an AI response. Review important claims against the original. A link included with your source does not mean the AI tool opened it or checked for a newer version.

Use counts as a check, not a target

Markdownizer reports a character count in its popup; that number is not the destination model's token count and does not indicate whether the whole prompt will fit. The receiving AI tool may count text, files, images, and conversation history differently. Consult that tool's current documentation or interface rather than converting a character count into a universal word limit.

Adding more text is not automatically better. A larger source can contain more context, but it can also make the relevant detail harder to locate and introduce contradictory versions. Conversely, trimming too aggressively can remove the line that explains an exception. The right amount is the smallest amount you can justify as complete for the question.

Recheck completeness and permission

Before sharing, confirm that the excerpt still contains the evidence needed to answer the question and that the AI service is approved for it. Review sensitive details, link query parameters, and any private context in the output. See what to review before sharing a webpage with AI.
