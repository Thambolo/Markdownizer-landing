Web access

Why can't ChatGPT read the link I sent?

A URL points to a page; it does not prove that the chat can open, retrieve, or interpret that page.

ChatGPT may not be able to read a link because the conversation has no web-search or browsing tool available, the tool is turned off, or the page cannot be accessed from that environment. A login, paywall, permission check, unsupported file type, temporary error, or page that loads content only after interaction can also get in the way. A link in your message is a reference, not the webpage contents.

Check whether web access is available

Look for a Search or browsing control in the current app, account, model, or workspace. Tool names and availability can change, and managed workspaces may have administrator controls. OpenAI's ChatGPT Search guide describes how web search can be started and how to review sources when search is available. That feature is not a promise that every URL will be fetched or that every answer will use a source.

If the tool is available, make the request explicit: "Open this public page, tell me whether you could access it, then answer the question using the page. Link each important claim to a source." If the assistant says it could not open the page, do not treat a general answer from memory as a page-specific answer.

Consider what might block the page

  • Account access: The page may require a sign-in, subscription, organization account, or browser session that is not available to the AI tool.
  • Page behavior: Some pages load their main content dynamically, require a button press, or expose only a limited preview.
  • Address or format: A copied link may have expired, contain a typo, point to an attachment, or redirect somewhere unexpected.
  • Tool restrictions: Search may be unavailable, limited by workspace policy, or unable to retrieve the particular source.
  • Access rules: A restriction is not an invitation to bypass it. Use a source you are authorized to access and share.

Provide the relevant content when permitted

If you can lawfully and appropriately share the page text, paste the specific section into the chat or attach a supported file if the destination accepts it. Include the page title, author or organization, publication or version date when relevant, and the original URL. Keep headings, table labels, units, and nearby caveats so that an excerpt is not misleading.

For a webpage you can view and are allowed to share, you can also copy or download a reviewed text conversion. Markdownizer converts the active webpage into Markdown; it does not open the URL for ChatGPT or check whether the AI has read it. Its conversion flow sends structural data to a backend, and copying the result into another service is a separate sharing step. See the privacy policy for the product's data-handling details.

Ask for an access report, then verify

Ask the tool to list which sources it actually used and to mark any inaccessible source as unavailable. Open the cited page yourself and check that it supports the answer. Search results and citations can be incomplete or outdated; the official guide recommends reviewing the source directly when accuracy matters.

For multiple pages, label each source and compare them separately rather than assuming one successful page means the rest were read. If you cannot share the source text, ask a question that can be answered without pretending to have seen it.
