Source checking

How do I get AI to cite the sources I provide?

Give each source a clear identity, ask for evidence near each claim, and verify the connection yourself.

To get an AI to cite sources you provide, label each source, include the relevant text or confirm that the tool actually accessed the page, and ask it to connect each factual statement to a source and location. Then open the source and check the support. A URL or citation format alone cannot guarantee that the tool read the page or produced a real, accurate reference.

Make the source easy to distinguish

For every item, provide a stable label, title, publisher or author, date or version, URL, and excerpt when you can share it. Use labels like [A] and [B] consistently in the prompt and requested answer. If a page is a changing reference, record when you viewed it so a reader can distinguish a later revision.

Source [A]
Title: Service setup guide
Publisher: Example Support
Version/date: 4.2, 2026-08-10
URL: https://example.org/setup
Excerpt: [the exact, relevant passage]

Use only the supplied sources. Put [A] after each claim it supports.
If a claim has no support, mark it "not supported by these sources."
Do not invent a title, quotation, date, or link.

The source and date are fictional examples. This format gives a reviewer a trail; it is not a citation generator or a guarantee that a response will obey the request.

Ask for support, not decoration

Request that the assistant use a short quotation, section heading, page number, or other locator when the source makes one available. Ask it to separate direct evidence from its explanation. For comparisons, request one citation per source-specific statement rather than a single citation at the end of a paragraph containing several claims.

If the AI has web search, ask it to say which pages it opened and cite sources for claims drawn from search. OpenAI's ChatGPT Search guide says responses using web search may include citations and directs users to review sources because results can be incomplete, outdated, or incorrect. Product features and workspace settings vary; do not assume a link was accessed just because it appears in a prompt.

Audit every citation

  1. Open the cited item and confirm the URL resolves to the expected publisher and page.
  2. Find the exact passage or table cell and check whether it supports the full sentence.
  3. Compare dates, units, definitions, scope, and caveats.
  4. Check for a citation that points to a related topic but does not support the claim.
  5. Mark unsupported details plainly, or remove them from the final answer.

A citation can be real but irrelevant, or point to a real source that says something narrower. A quotation can also be miscopied. When the exact wording matters, compare the quote character by character and keep enough context to preserve its meaning.

Keep links and excerpts useful

When several pages are involved, keep source blocks separate instead of pasting a long undifferentiated text. The multiple-webpage workflow shows how to compare them without losing source identity. For notes that you revisit later, retain the original links and dates; see how to keep source links in research notes.

Do not include restricted or confidential material unless the relevant owner and service policy allow it. If you need to bring a webpage into a prompt, inspect the converted result and its links before sharing. Markdownizer can capture the active page as Markdown, but it does not verify citations or claim support.
