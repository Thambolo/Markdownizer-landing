Download options

How to download webpage images alongside Markdown

The optional ZIP bundles the converted Markdown with images it can fetch; it is not a complete offline copy of a site.

Markdownizer's normal Markdown output can contain image references, but it does not by itself save those image files beside the document. To bundle local copies of eligible referenced images, turn on Download images and use the ZIP export. The ZIP contains the Markdown, a README.md, and an images/ folder; image paths in the bundled Markdown are rewritten to point to that folder.

The option is off by default and its preference persists locally. It may request optional site-access permission to fetch images. The bundle includes fetchable image references found in the converted Markdown, not every visual asset visible on the page. The feature guide lists current export behavior and limits.

What the ZIP is useful for

A bundle can help when you want a notes folder that keeps a document and some of its referenced images together, or when you want to review supported image files alongside the source text. It does not make a remote website wholly available offline, preserve its layout, or guarantee that an image will still be served in the future.

It is also different from adding image understanding to the Markdown. The ZIP includes files and rewritten paths. It does not perform OCR, generate image descriptions, or embed the image's visual contents into the text. Whether a later AI application can read uploaded images depends on that application and your account or tool settings.

Use the optional image export

  1. Open the webpage in the browser and make sure the text and image references you need are present.
  2. Enable Download images in the Markdownizer popup if you want the ZIP workflow. Browser permission may be requested for the site.
  3. Start conversion and review the Markdown output. The image bundle is based on references in the converted Markdown.
  4. Save and inspect the ZIP. Check the Markdown, README, image files, and rewritten paths. Confirm that the images important to your task are actually included.
  5. Move the unpacked folder as a unit if you want its relative image paths to continue resolving.

When image bundling is enabled, its ZIP download path takes precedence over the separate automatic Markdown download path. The setting does not mean every conversion will produce a complete set of image files.

Know which images may be missing

Only fetchable images referenced in the converted Markdown are candidates. A blob: image, a failed or unavailable resource, or an image that exceeds the limits can be skipped. The current limits are 15 MB per image, 60 MB total, and a 10-second fetch timeout. A page may also show visuals through CSS, scripts, a canvas, or a lazy-loading pattern that does not result in a fetchable Markdown image reference.

Review the ZIP instead of assuming that the folder mirrors the page. If a chart or diagram is essential and missing, consult an authorized source download or keep a separately reviewed screenshot. Do not treat the ZIP as an archival backup or an offline site mirror.

Keep the text and image context connected

After unzipping, check that each local reference points to a file that exists and that the adjacent heading or caption explains what the image belongs to. If you edit or move the Markdown, preserve the relative paths or update them. A file may be present without being meaningful on its own; keep source labels and notes next to important illustrations.

For text-only tasks, a standard Markdown file may be simpler. Read how to save a webpage as a Markdown note. To decide whether a visual or text representation is more appropriate, compare Markdown and screenshots for AI context.

Review permission and privacy before exporting

Confirm that you may save the page's images and share them with your intended destination. A logged-in page or private workspace may have separate rules even when it is visible to you. Markdownizer tokenizes readable page text locally, sends a structural skeleton that may include image references and other attributes to the backend, and rebuilds readable Markdown in the browser. Image fetching is a separate optional step; read the privacy policy and review the destination service before sharing the resulting files.
