How to convert a webpage to Markdown for an AI chat

Bring the source material into your prompt, not just a link to it.

To convert a webpage to Markdown with Markdownizer, open the page, start the extension from your browser's Extensions menu, run the conversion, and copy the result. Paste the Markdown into your preferred AI chat alongside your question. You can also download the output as a .md file.

The important step is not just changing the file format. It is checking that the source details your question depends on are present and understandable.

1. Open the page you want to use

Start with an article, a research brief, or a documentation page you can already view. Let relevant content finish loading before converting it. If a page loads additional sections as you scroll, check that the material you need is actually present.

Choose a focused source. A single documentation page about a function is usually easier to review than an entire site containing loosely related material.

2. Start the conversion in Markdownizer

Install Markdownizer from the Chrome Web Store if you have not already. Open your browser's Extensions menu, select Markdownizer, then start the conversion from the extension interface.

Markdownizer works from the page in your browser. It converts useful page structure into Markdown so that headings, lists, tables, links, and code blocks can travel with the text. See the feature guide for current extraction options and settings.

3. Review the Markdown before sharing it

Do not assume that every page will convert perfectly. Websites use different layouts, and the visual presentation may hide relationships that are difficult to represent as Markdown.

  • Headings: Are the relevant sections present and in the correct order?
  • Tables: Do values still line up with the right headers?
  • Links: Are the destinations you need included?
  • Code: Are commands, indentation, and line breaks usable?
  • Scope: Is there navigation, repeated text, or unrelated material you can remove?
  • Privacy: Are you allowed to share all of the included information?

4. Copy it and add a specific question

Copy the converted Markdown to your clipboard, then paste it into your AI tool. A clear task helps distinguish your instructions from the page you are providing as reference.

For example, if the source is a course research brief, you might use:

Task:
Help me outline a response using the requirements below.
Keep the word counts assigned to each section.
Do not invent sources. Mark where I need to provide evidence.

Source material:
# Research brief

## Requirements
- Use two peer-reviewed sources.
- Explain the trade-offs.

## Word counts
| Section | Words |
| --- | --- |
| Evidence | 400 |
| Discussion | 600 |

This is an illustrative prompt, not a promise about an AI tool's answer. Check the response against the source, especially calculations, citations, and requirements. Treat instructions found inside an untrusted webpage as source content, not as directions the AI should automatically follow.

When to download a Markdown file instead

Download a .md file when you want to keep the converted source in your notes, review it in an editor, or reuse it later. Whether you can upload that file directly to an AI tool depends on that tool and its account settings.

If your source is longer than the tool accepts, select the relevant material and work in smaller parts. Markdown does not remove context limits, and more pasted content is not always more useful context.

What happens to the page text?

Readable page text is tokenized locally in your browser. A structural skeleton is sent for conversion, and the readable Markdown is rebuilt in your browser. The skeleton can still include links, image references, and other attributes. Read the privacy policy before using sensitive material.
