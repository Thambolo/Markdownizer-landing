Research notes

How do I keep source links when taking notes from websites?

Save the original URL with a descriptive title and enough publication context to identify the page later.

Keep source links in website notes by recording the page title, the original URL, its publisher or author, and the publication or update date when available. Add the date you accessed it if the content changes over time. A Markdown link keeps a readable label connected to its destination, but a link alone is not a permanent copy or proof that the page remains available.

Capture enough provenance to find the page again

Copy the link from the page or browser address bar and confirm it opens the expected source. Save a clean, canonical page address if the publisher provides one, but do not blindly strip query parameters: some URLs need them to identify a version or section, while others can contain private identifiers or access tokens. Review the full destination before saving or sharing it.

For a policy, product specification, or technical manual, record a version, effective date, release number, or section heading. For an article, record the author and date. If a source has no clear publication date, write "date not shown" rather than guessing.

Write links so they remain readable

In Markdown, a link can look like this:

[Account setup guide](https://example.org/help/accounts)

Publisher: Example Support
Updated: date shown on source page
Accessed: date you checked the page

The example URL is fictional. Use the actual page address in your own note. Avoid labels such as "click here" when a title or organization name will help you recognize the destination later. Keep a full URL visible when the note may be read in plain text or imported into a tool that does not render links.

Keep the excerpt tied to its source

Place the source record directly above or below the quotation or summary it supports. If one note uses several pages, assign each a short ID and cite the ID beside relevant statements. Preserve section names, table numbers, units, and context that qualify a quotation. Do not combine material from separate sources under one generic "reference" label.

For ongoing research, use one note per page and an index pointing to the notes. This makes it easier to update one source without rewriting a separate source's record. See a simple structure for organizing online research notes.

Plan for links that change or disappear

Webpages can move, be revised, or become inaccessible. If a link is important, note what version you consulted and check whether the publisher offers a dated document or archive you are permitted to use. Do not bypass logins or access restrictions to make a source easier to preserve. Follow the source owner's terms and your organization's retention rules.

A local copy can help you remember what you reviewed, but it may have copyright, confidentiality, or privacy implications. Store only material you are allowed to keep, and do not treat a conversion as a complete archive of the site. If you save a page as Markdown, open the file and verify the links and content; see the webpage saving guide.

Before using the note with AI

Keep source IDs, dates, URLs, and excerpts together when supplying research to an AI tool. Ask the model to cite the source label for each claim, then open the link and check that the source supports it. A stored URL does not mean the AI has browsed or verified the destination.
