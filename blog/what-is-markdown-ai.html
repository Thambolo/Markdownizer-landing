Markdown basics

What is Markdown, and why do AI tools use it?

Markdown is readable text with simple markers that describe document structure; it is a format, not an AI feature.

Markdown is a plain-text way to mark up the structure of a document with simple characters. A hash mark can introduce a heading, a dash can begin a list item, and backticks can mark code. People use it for notes, documentation, websites, and other text because the source stays readable even before it is rendered.

A small example

# Setup notes

Use the current release.

## Before you begin
- Check the version number.
- Keep the warning with the command.

`--dry-run` previews an operation.

A Markdown viewer may render the first line as a large heading and the two dash-prefixed lines as a list. In the raw file, the words and their relationships are still visible. A link can be written as [Guide](https://example.org/guide); a fenced code block can preserve sample commands and indentation.

Why it can be useful with AI

When an AI tool receives Markdown, headings and lists can make some relationships explicit in text: a heading names a section, bullets separate items, and a link label stays paired with its destination. Code fences distinguish sample code from surrounding explanation. This can make a source easier for a person to review and can give a text-based workflow a more structured representation.

That does not mean Markdown automatically improves every answer, saves a predictable number of tokens, or is required by every AI app. Simple plain text may be enough for a short request. The useful question is whether the structure preserves distinctions your task depends on. See Markdown vs. ordinary copy-paste and what actually saves tokens.

Markdown has variations

There is more than one Markdown dialect. CommonMark specifies core syntax such as headings, lists, links, and code blocks; platforms may add extensions. Tables, task lists, and strikethrough are not handled identically by every basic Markdown parser. If a file moves between apps, preview it in the destination and check any extended syntax you rely on.

The CommonMark specification describes Markdown as a plain-text format for structured documents and explains core parsing rules. Its examples also illustrate why a heading or code fence should be checked in the renderer you actually use.

What Markdown cannot represent by itself

Markdown is primarily a text format. It does not preserve the full visual layout of a webpage, and an image link is not the same as the image's meaning. A table flattened into text may lose merged-cell relationships or styling. A link in a Markdown file does not mean an AI assistant opened the linked page. Keep the original source or screenshots when visual details matter and the destination can process them.

Markdown also does not verify truth, remove hidden instructions, sanitize private information, or expand an AI tool's context window. Review the source and output, and check what the receiving app supports.

How to start using it

Write plain text with headings and lists, save it as a .md file, and open it in a text editor or Markdown-capable app. To bring a webpage into a note or prompt, you can copy or download a Markdown conversion and inspect it before reuse. Markdownizer is one option for converting the active webpage; it does not create summaries or check factual accuracy.

For editing options, see how to open and edit a .md file. For a quick reference to syntax, consult the CommonMark tutorial and reference.
