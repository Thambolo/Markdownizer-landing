Prompt troubleshooting

Why does AI ignore some of my instructions?

A missed requirement can come from a conflict, an unclear request, missing context, or a tool limitation; it does not necessarily have one obvious cause.

An AI may miss an instruction when the request is ambiguous, two requirements conflict, an important rule is buried among details, or the requested action is unavailable to the tool. It can also simply produce an imperfect response. The best fix is to identify the specific miss, reduce ambiguity, and check the next output against a short list of requirements rather than assuming one wording trick will guarantee compliance.

Look for requirements that compete

"Explain every detail in one sentence" asks for incompatible levels of detail. "Use only this article, but include the latest price" asks for information the supplied article may not contain. Decide which requirement has priority, or split the task into steps. Ask the assistant to flag a conflict before answering instead of silently guessing which request matters more.

Replace vague words with observable outcomes

Terms such as "good," "brief," "professional," or "complete" mean different things to different readers. Describe the result you want: "Write three bullet points, each under 25 words, and include the date and exception" is easier to inspect than "keep it concise but thorough." Avoid asking for an exact style and a contradictory format at the same time.

Put the task and priority first

Start with the main action. Then list non-negotiable constraints, the source material, and the output shape. If there are many criteria, number them and say which ones are essential. Keep examples separate from requirements so the AI does not mistake sample content for a second task.

Task: Extract the eligibility rules from the excerpt below.
Required:
1. Keep each exception beside the rule it qualifies.
2. Use only the supplied excerpt.
3. Write "not stated" for missing information.
Output: A table with Rule, Exception, and Evidence columns.
If any requirement conflicts with another, ask before proceeding.

This is a clarity aid, not a guarantee. For more on separating the instruction from quoted material, read how to separate instructions and reference text.

Check what the tool can actually do

A prompt cannot enable a tool that is unavailable. If the request asks the assistant to open a webpage, search the internet, inspect an attachment, or run code, check that the relevant capability exists in that product and conversation. Availability and limits can vary by model, account, app, and workspace. If a URL was not retrieved, provide appropriate source text instead of repeating the request as if access were certain.

Test the result against a checklist

  1. Choose the two or three requirements whose omission would matter most.
  2. Ask for one bounded task at a time if the original prompt mixes research, analysis, and drafting.
  3. Review the answer against each requirement, not only whether it sounds confident.
  4. Point to the exact missed criterion and ask for a correction based on the supplied information.
  5. Check any factual or high-impact output against authoritative sources or a qualified reviewer.

Repeating the same request more forcefully is not a reliable fix. If the content is long, relevant material may be hard to track; if instructions conflict, a more detailed prompt can add confusion. See what a context window means and how to give an AI useful context.

For sensitive or consequential work, do not rely on prompt wording alone. Keep permissions and tool access limited to what is needed, review actions before they happen, and verify the output independently.
